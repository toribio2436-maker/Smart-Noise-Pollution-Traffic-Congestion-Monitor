# Smart-Noise-Pollution-Traffic-Congestion-Monitor
Sistem pemantauan kebisingan lalu lintas, kepadatan kendaraan, dan polusi udara real-time berbasis **Edge Computing (Edge AI)** dan **IoT**.   Proyek ini dibangun untuk memenuhi kriteria tugas IoT dengan memanfaatkan **2 Edge Devices** (HP Android + ESP32), **2 Jenis Data Processing**, **2 Sensor Fisik**, serta **MQTT Cloud Protocol**.
